# EE1259 Russian Translation

Фанатский перевод с помощью ИИ с ручным отбором и проверкой. Сверял с употреблением терминов на русском языке, чтобы перевод был не просто переводом транслита в кириллицу, цели исправить оригинал не стояло, но часть адаптации под русский язык имеется.

Ошибки возможны, вы можете он них сообщить. Я не историк, не переводчик и могу ошибаться в этих областях.

Этот проект, я делаю лично для себя и не претендую на безоговорочную истину в переводе некоторых топонимов и имен собственных. Особенно в их склонении. Я сделал так, как нравится мне. Тем не менее, если вам нужно - вы можете его использовать.

- Старался сохранить стиль оригинального перевода M&B2
- Поддерживаются падежи и склонения (из-за чего пришлось доработать обработчик для склонения имен)
- Полностью читаю строки из файлов мода, а не использую шаблон от разработчика, за счет чего:
  - Актуализировал строки, которые в шаблоне устарели
  - Перевёл то, чего не было в шаблоне

## Установка

(Это отдельный мод, он не заменяет файлы мода или игры)

1. Положить `EE1259_RU_Localization` и `RussianTextProcessorFix` в `./Mount & Blade II Bannerlord/Modules`
2. В порядке загрузки:
    - `EE1259_RU_Localization` в любое место после `LT_EE1259_Assets`
    - `RussianTextProcessorFix` поставить в самый низ

## Изменения языкового обработчика

1. В Р.п. мн.ч. у слов, гра­фи­че­с­кая ос­но­ва которых ока­н­чи­ва­е­т­ся на "ц", заменена на "ж", согласно 4ому склонению по А. А. Зализняку (<https://gramdict.ru/declension/symbols#indices-3-7>)

**Исправлено**

| И.п. ед.ч | Было     | Стало    |
| --------- | -------- | -------- |
| нож       | ножов    | ножей    |
| мудрец    | мудрецей | мудрецов |
| кузнец    | кузнецей | кузнецов |

**Регресс**

Не замечен

2. В Т.п. для слов с окончанием на ович/евич окончание заменено с "ом" на "ем".

Сделано для отчеств, вообще это определяется ударением, но зачастую такое условие срабатывает.

**Исправлено**

| И.п. ед.ч  | Было         | Стало              |
| ---------- | ------------ | ------------------ |
| Ильич      | Ильичом      | Ильичом (без изм.) |
| Васильевич | Васильевичом | Васильевичем       |
| Иванович   | Ивановичом   | Ивановичем         |

**Регресс**

| И.п. ед.ч  | Как правильно | Как сейчас (НЕПРАВИЛЬНО)  |
| ---------- | ------------- | ------------------------- |
| Пскович    | Псковичом     | Псковичем                 |
| Рядович    | Рядовичом     | Рядовичем                 |
| Дрегович   | Дреговичом    | Дреговичем                |

3. Не работало условие правила склонения слов оканчивающихся на ек/ёк, заменил его на просто "Слова оканчивающиеся на ёк", из-за чего правило в принципе стало работать, но чувствительно к е/ё (не чувствительным сделать не смог, иначе много ошибок)

**Исправлено**

| И.п. ед.ч  | Было         | Стало              |
| ---------- | ------------ | ------------------ |
| огонёк     | огонёка      | огонька            |
| мотылёк    | мотылёка     | мотылька           |
| кошелёк    | кошелёка     | кошелька           |
| паёк       | паёка        | пайка              |

**Регресс**

Слова с ёк в корне слова, а не в суффиксе: тёк, пёк, щёк (кровоподтёк, намёк, солнцепёк)

4. Добавлен тег `{.PR}` для местоимённого склонения по А. А. Зализняку.

В ТЕОРИИ разметка с данным тегом совместима с дефолтным RussianLanguageProcessor.

Например, {.PR}{.FA}Иванова{.nn}

| Падеж | Было     | Стало    |
| ----- | -------- | -------- |
| Р     | Ивановы  | Ивановой |
| Д     | Иванове  | Ивановой |
| В     | Иванову  | Иванову  |
| Т     | Ивановой | Ивановой |
| П     | Иванове  | Ивановой |

Например, {.PR}{.MA}Иванов{.nn}

| Падеж | Было     | Стало    |
| ----- | -------- | -------- |
| Т     | Ивановом | Ивановым |

### Известные проблемы

- Формы слов оканчивающихся на суффикс ец склоняются неверно, исправить это каким-либо условием не вышло, т.к. правило написания зависит от ударения
- Костыль для этого "EE1259_RU_Localization\ModuleData\russian_declension_exceptions.xml" - словарь слов с прописанными для них формами. Те формы, где алгоритм языкового обработчика не ошибается, можно не указывать.
