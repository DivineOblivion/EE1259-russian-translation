# Русификатор для мода Eastern Europe 1259 (EE1259) на Mount & Blade II: Bannerlord

## EE1259 Russian Translation with Grammatical Declensions

Фанатский перевод для мода [Eastern Europe 1259](https://www.nexusmods.com/mountandblade2bannerlord/mods/6724) с поддержкой склонений/падежей.

Перевод выполнялся с помощью ИИ с ручным отбором и проверкой. Сверял с употреблением терминов на русском языке, чтобы перевод был не просто переводом транслита в кириллицу, часть адаптации под русский язык имеется.

Ошибки возможны, вы можете он них сообщить. Я не историк, не переводчик и могу ошибаться в этих областях.

Этот проект, я делаю лично для себя и не претендую на безоговорочную истину в переводе некоторых топонимов и имен собственных. Особенно в их склонении. Я сделал так, как нравится мне. Тем не менее, если вам нужно - вы можете его использовать.

## Особенности

- Старался сохранить стиль оригинального перевода M&B2
- Поддерживаются падежи и склонения
- Доработанный обработчик русского языка для склонения всего и вся
- Полностью читаю строки из файлов мода, а не использую шаблон от разработчика, за счет чего:
  - Актуализировал строки, которые в шаблоне устарели
  - Перевёл то, чего не было в шаблоне

Для работы требуются следующие модификации:

- Harmony: [Harmony on NexusMods](https://www.nexusmods.com/mountandblade2bannerlord/mods/2006) (Так же необходим для работы EE1259)

## Установка

(Это отдельные моды, они не заменяют на прямую файлы мода или игры. Кроме `ee_tips.txt` в `LT_EE1259_Map13`, другого способа их перевести - нет)

1. Положить содержимое папки `Modules` в `./Mount & Blade II Bannerlord/Modules` (можно выборочно):
   - Для руссификации подсказов на экране загрузок преместите `LT_EE1259_Map13` в `./Mount & Blade II Bannerlord/Modules` с заменой файла `ee_tips.txt`.
   - `EE1259_RU_Localization` и `RussianTextProcessorFix` основаные моды для руссификации мода EE 1259.
   - `Diplomacy_RU_Localization` для руссификации мода `Diplomacy`. (если используете, рекомендованный мод для установки вместе с `EE 1259`)
   - `RBM_RU_Localization` для руссификации мода `RBM` (+`RBM_WS`). (если используете, рекомендованный мод для установки вместе с `EE 1259`)
2. Порядок загрузки:
    - `RussianTextProcessorFix` поставить в самый низ
    - `EE1259_RU_Localization` в любое место после `LT_EE1259_Assets`
    - `Diplomacy_RU_Localization` в любое место после `Bannerlord.Diplomacy`
    - `RBM_RU_Localization` в любое место после `RBM`

## Подробнее

### EE1259_RU_Localization

Локализация мода `Eastern Europe 1259` на русский язык в виде отдельного мода с поддержкой склонений.

### Diplomacy_RU_Localization

Локализация мода `Diplomacy` на русский язык в виде отдельного мода с поддержкой склонений.

### RBM_RU_Localization

Локализация мода `RBM` на русский язык в виде отдельного мода с поддержкой склонений.

Добрая половина остаётся на английском, т.к. разработчик не предоставил возможности для перевода в моде: <https://github.com/Fellow93/RealisticBattleProject/pull/20>

### RussianTextProcessorFix

Мод, исправляющий языковой обработчик. Имеются некоторые улучшения и изменения в строках из оригинальной игры только для поддержания правильного склонения слов.

#### Изменения языкового обработчика

1. В Р.п. мн.ч. у слов, гра­фи­че­с­кая ос­но­ва которых ока­н­чи­ва­е­т­ся на "ц", заменена на "ж", согласно 4ому склонению по А. А. Зализняку (<https://gramdict.ru/declension/symbols#indices-3-7>)

**Исправлено**

| И.п. ед.ч | Было     | Стало    |
| --------- | -------- | -------- |
| нож       | ножов    | ножей    |
| мудрец    | мудрецей | мудрецов |
| кузнец    | кузнецей | кузнецов |

**Регресс**

Не замечен

2. В Т.п. для слов с окончанием на ович/евич окончание заменено с "ом" на "ем".

Сделано для отчеств, вообще это определяется ударением, но зачастую такое условие срабатывает.

**Исправлено**

| И.п. ед.ч  | Было         | Стало              |
| ---------- | ------------ | ------------------ |
| Ильич      | Ильичом      | Ильичом (без изм.) |
| Васильевич | Васильевичом | Васильевичем       |
| Иванович   | Ивановичом   | Ивановичем         |

**Регресс**

| И.п. ед.ч  | Как правильно | Как сейчас (НЕПРАВИЛЬНО)  |
| ---------- | ------------- | ------------------------- |
| Пскович    | Псковичом     | Псковичем                 |
| Рядович    | Рядовичом     | Рядовичем                 |
| Дрегович   | Дреговичом    | Дреговичем                |

3. Не работало условие правила склонения слов оканчивающихся на ек/ёк, заменил его на просто "Слова оканчивающиеся на ёк", из-за чего правило в принципе стало работать, но чувствительно к е/ё (не чувствительным сделать не смог, иначе много ошибок)

**Исправлено**

| И.п. ед.ч  | Было         | Стало              |
| ---------- | ------------ | ------------------ |
| огонёк     | огонёка      | огонька            |
| мотылёк    | мотылёка     | мотылька           |
| кошелёк    | кошелёка     | кошелька           |
| паёк       | паёка        | пайка              |

**Регресс**

Слова с ёк в корне слова, а не в суффиксе: тёк, пёк, щёк (кровоподтёк, намёк, солнцепёк)

4. Добавлен тег `{.PR}` для местоимённого склонения по А. А. Зализняку.

В ТЕОРИИ разметка с данным тегом совместима с дефолтным RussianLanguageProcessor.

Например, {.PR}{.FA}Иванова{.nn}

| Падеж | Было     | Стало    |
| ----- | -------- | -------- |
| Р     | Ивановы  | Ивановой |
| Д     | Иванове  | Ивановой |
| В     | Иванову  | Иванову  |
| Т     | Ивановой | Ивановой |
| П     | Иванове  | Ивановой |

Например, {.PR}{.MA}Иванов{.nn}

| Падеж | Было     | Стало    |
| ----- | -------- | -------- |
| Т     | Ивановом | Ивановым |

#### Известные проблемы

- Формы слов оканчивающихся на суффикс ец склоняются неверно, исправить это каким-либо условием не вышло, т.к. правило написания зависит от ударения
- Костыль для этого "EE1259_RU_Localization\ModuleData\russian_declension_exceptions.xml" - словарь слов с прописанными для них формами. Те формы, где алгоритм языкового обработчика не ошибается, можно не указывать.
